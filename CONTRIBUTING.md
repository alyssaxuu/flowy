# Contributing to Flowy

Thanks for your interest in contributing! We welcome contributions of any size — bug reports, documentation updates, small fixes, or demos.

## Getting started

- Fork the repository on GitHub.
- Clone your fork:

  ```bash
  git clone https://github.com/<your-username>/flowy.git
  cd flowy
  git checkout -b my-feature-or-fix
  ```

- Make small, focused changes. Keep pull requests (PRs) readable and scoped to one topic.

## Development notes

- The repository includes a `demo/` folder with example files (`demo/index.html`, `demo/main.js`). You can open `demo/index.html` in your browser to try the library locally.
- Follow the existing code style when adding or modifying JavaScript.

## Reporting issues

- For bugs or feature requests, open an issue and include a minimal reproduction (code samples, browser and OS, screenshots).

## Pull request process

1. Create a branch: `git checkout -b yourname/short-description`
2. Make your changes and run any local checks (open demo to verify behavior).
3. Commit with a clear message (imperative tense): `Add`, `Fix`, `Update` — e.g. `Fix: prevent drag glitch on touch devices`.
4. Push your branch to your fork and open a PR against the `master` branch of `Dayifour/flowy`.
5. In the PR description, explain what changed, why, and include screenshots or links to demos if appropriate.

## Code of Conduct

This project follows a Code of Conduct. By participating, you agree to abide by its terms. See `CODE_OF_CONDUCT.md` for details.

## Contributor tips

- Keep changes minimal and focused.
- If a change is non-trivial, open an issue first to discuss the approach.
- Be responsive to feedback in PR comments and iterate as needed.

Thank you for contributing — every bit helps!
