# Code of Conduct

This project and everyone participating in it is governed by this Code of Conduct. By participating, you agree to abide by its terms.

## Our Standards

We expect contributors and maintainers to follow these standards:

- Be respectful and considerate in communications.
- Harassment, discrimination, or abusive behavior will not be tolerated.
- Be collaborative and open to constructive feedback.

## Reporting Guidelines

If you experience or witness unacceptable behavior, please report it by contacting the project maintainers. You can file a confidential report by emailing: `hi@alyssax.com`.

## Enforcement

Project maintainers will respond to reports and may take actions including warnings, temporary or permanent bans from project spaces, or other measures to ensure a safe environment.
